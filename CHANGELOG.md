# Журнал змін

## 24.11.2026 — E02.1

- Мобільна форма підписує ідентифікатор партії. Сервер фіксує відбиток разом із JPEG у контрольній точці. Повтор повертає стан уже збереженої партії, навіть якщо клієнт не отримав оновлене cookie.
- Відмінний вміст і застарілий контекст дають 409. Збій запису нових файлів повертає попередній стан редактора. Форма зберігає підготовлені файли в межах сторінки, щоб мережевий повтор надсилав ті самі байти.
- Для старих клієнтів без ідентифікатора партії збережено сумісність форми; гарантія повтору поширюється на оновлену мобільну форму. Серіалізацію через локальний lock перевірено для одного процесу Gunicorn.

## 24.11.2026 — E01
