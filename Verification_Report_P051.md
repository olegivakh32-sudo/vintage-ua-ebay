## Порівняння США та України

Додано сторінку `/markets/compare`, доступну з навігації програми. Ціна США та доставка покупця підставляються з наявної чернетки, якщо вона є. Порівняння не змінює лот, не публікує його та не викликає API.

Усі суми рахуються через Decimal. Враховуються ціна товару, доставка, сплачена покупцем, фактична доставка, змінна та фіксована комісія, пакування, собівартість, інші витрати й введений курс. Комісія застосовується до товару плюс доставки покупця. Податки, реклама, конвертація та резерв повернень мають бути включені оператором у відповідні витрати. Для індивідуального продажу порівнюйте одну одиницю; для продажу набором — весь набір.

Порожня витрата не прирівнюється до нуля: її потрібно заповнити явно. Від’ємний прибуток показується. Результат завжди позначено як сценарний. Поля джерел і дати — записи оператора; автоматичної перевірки джерел немає. Ціни активних оголошень не видаються за фактичні продажі. Автоматичне дослідження українського ринку ще не реалізоване.

Контрольний приклад: за курсу 40, ціни США $20, оплати доставки покупцем $10, комісії 15% + $0.30, фактичної доставки 300 грн, пакування 20 грн, інших витрат 10 грн та собівартості 100 грн прибуток США = 578.00 грн. За ціни України 600 грн, оплати доставки 50 грн, комісії 5% + 2 грн, фактичної доставки 50 грн, пакування 10 грн та інших витрат 5 грн прибуток України = 450.50 грн. Різниця = 127.50 грн.

## Перевірки

**51/51 тестів — PASS.** 12 успадкованих перевірок структури/осей і 39 перевірок виконання та розрахунків. Кількість тестових методів не означає 51 реальний товар або 51 публікацію.

- Реальний Flask test client: сторінки, помилкові дані, підтвердження ціни й доставки, збереження/відновлення, прямі посилання після втрати пам’яті.
- Відновлення: 93 г не повертаються до 99 г; свіжа ціна не затирається; старі фото не замінюють нові; старий номер лота не замінює новий.
- Передача осей: length/width/thickness, квадратні предмети, конфліктні виміри та відсутні позначення.
- Фото: вибір головного зберігає послідовність решти фотографій.
- Імітація eBay: GET фінального підтвердження не публікує; POST публікує один раз після повторної перевірки; інший заголовок у відповіді eBay блокує публікацію; помилка 25002 залишає HOLD без повторного AI; наявний UNPUBLISHED Offer не створюється повторно.
- AI: чинний ліміт викликів зупиняє новий запит; після імітованої insufficient_quota повторний виклик не надсилається.
- Фінанси: арифметика, комісія з доставки, збиток, рівні результати, перевага кожного ринку, кома в числах, порожні/нескінченні/недопустимі значення, екранування введеного HTML.
- Python compile та відсутність дублів маршрутів — PASS.
- Окремий процес `python app.py`: `/health` → 200, `/markets/compare` → 200, `/ebay/current-preflight` без лота → 400, `/ebay/current-publish` без лота → 409, головна → 200.

Знайдені регресії спочатку відтворено на P050, потім перевірено на виправленій програмі. Тест успадкованого контракту, який засвідчував відсутність функції порівняння, оновлено відповідно до доданої функції; решта його логіки збережена.

**Реальних платних API-викликів у цій роботі: 0.** Зовнішній HTTP у тестах заблоковано, відповіді OpenAI/eBay підмінено. Платні механізми в самій програмі залишаються: аналіз фото, web research і створення тексту використовують налаштований OpenAI API за чинним сценарієм. Стверджувати нульову вартість робочого лота не можна.

## Запуск і відтворення

1. Використовуйте `app.py` як один файл програми. У цій роботі хостинг і репозиторій не змінювалися.
2. Збережіть чинні налаштування Google/eBay/OpenAI. Для Render потрібен `APP_SECRET`. Реквізити не включено у файл чи звіт.
3. Збережіть чинні requirements; додаткових сторонніх залежностей P051 не додає. Перевірено на Python 3.12, Flask 3.1.3, Pillow 12.3.0, requests 2.34.2.
4. Для існуючого Gunicorn-проєкту точка входу залишається `app:app`. Через локальні кеші ця збірка розрахована на одну копію процесу; кілька workers потребують спільного сховища стану. `python app.py` придатний для локальної перевірки.
5. Для збереження після перезапуску використовуйте `ACTIVE_LOT_CHECKPOINT_DIR` на постійному диску. Без нього `/tmp` може бути втрачений при перевстановленні/заміні інстансу. Знімки не містять схвалених JPEG і токенів; тимчасові посилання Google можуть протермінуватися.
6. Розпакуйте архів тестів біля `app.py`, виконайте `python3 -m unittest discover -s . -v`. Файл `test-results.txt` містить журнал перевіреної збірки. Під час тестів не потрібні API-ключі.
