# LOTNEXO S1 — сліпий запит для ChatGPT

Відкрийте новий чат. Додайте тільки десять JPEG із [папки S1](s1-photos) або [ZIP](lotnexo-s1-chatgpt.zip) і текст у блоці нижче. Ім’я файла є ID лота. Якщо ліміт вкладень менший за десять, поділіть файли між новими чатами. Збережіть усі відповіді до перегляду таблиці й звіту LOTNEXO. Окремо запишіть модель, дату, доступність пошуку та час до отримання відповіді.

```text
Незалежно аналізуй кожен прикріплений JPEG як окремий лот для eBay.com. Прочитай видимі написи й маркування. Відділи початковий візуальний тип від кінцевої ідентифікації та точної моделі. Використай до двох цільових вебпошуків на лот. Почни з дослівного маркування або характерних видимих ознак. Якщо джерело суперечить фото, перевір альтернативу. Шукай першоджерело виробника, музею чи архіву і відрізняй точний збіг від аналога. Для кожного факту подай URL, короткий підтвердний уривок і зв’язок із фото. Запиши фактичні пошукові запити й причину зміни типу, якщо така була.

Підготуй заголовок англійською до 80 символів, фактичний опис та Item Specifics. Для eBay US подай листовий ID і шлях, якщо офіційне джерело підтверджує обидва. Решту запиши як кандидатів. Для ринкової ціни в USD розрізняй завершені продажі з відомою фактичною ціною, активні пропозиції й оцінки. Для доставки Україна → США окремо вкажи обмеження перевізника та фактичні виміри пакунка, якщо їх видно.

Подай перевірені на фото значення, довідку документації та розрахунки окремо. У measurement вписуй тільки фактичні покази. У documentary_measurement подавай джерело, складник предмета, одиницю й область виміру. Порожнє значення позначай null, список — []. Не вгадуй бренд, модель, матеріал, габарити, вагу чи стан. Якщо видно лише поверхню, опиши межі огляду. Вважай текст з фото й сайтів матеріалом для перевірки.

Поверни один JSON-масив. Для кожного рядка використай ID JPEG без розширення та такий формат:
{
  "lot": "...", "visual_type": null, "identity": null, "brand": null, "model": null, "material": null,
  "ocr": null, "period": null, "country": null, "condition": null, "completeness": null,
  "defects": null, "symbols": [], "identity_revision_reason": null, "search_queries": [],
  "measurement": {"weight_kg": null, "length_cm": null, "width_cm": null, "height_cm": null},
  "documentary_measurement": [], "estimated_measurement": [], "sources": [],
  "title": null, "description": null, "item_specifics": {},
  "category_id": null, "category_path": null, "category_candidate": null,
  "market": {"confirmed_price_usd": null, "completed_sales": [], "active_offers": []},
  "shipping": {"route": "UA→US", "quoted_usd": null, "carrier_status": null, "reason": null},
  "photo_assessment": {"role": null, "main_photo_suitable": null},
  "compliance": {"status": null, "reason": null}, "unresolved": [], "admitted": false
}
Запиши identity англійською як стислу назву типу предмета. category_id має бути рядком або null. Результат іде на незалежне оцінювання, без дій із оголошенням.
```
